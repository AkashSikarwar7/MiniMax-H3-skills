# MiniMax H3 Skills

A reusable Codex skill for writing RunDiffusion-ready MiniMax H3 prompts.

## Included

- SKILL.md — routing and prompting guidance
- references/prompt-templates.md — compact prompt scaffolds and checklists
- agents/openai.yaml — optional UI metadata

The guidance is distilled from the [RunDiffusion MiniMax H3 Prompt Guide](https://www.rundiffusion.com/minimax-h3-prompt-guide).
